# Slide-a-Key Musical Transposer

**No batteries! No app! No subscription!**

Slide-a-Key is a free, printable paper tool for moving notes, melodies and chord charts from one key to another. Line up the key you're in with the key you want, then read off the matching notes. It works in all 12 keys.

**Visit the website: [www.slideakey.com](https://www.slideakey.com)**. You can try it on screen there before you print.

This repository holds the files for that website.

## Print Your Own

| Edition | How it works |
|---|---|
| [Classic](slide-a-key_musical_transposer_classic_edition.pdf) | Cut off the slider strip and slide it along the fixed strip below. |
| [Tent](slide-a-key_musical_transposer_tent_edition.pdf) | Fold the slider over the top edge of the page so it hooks on and slides along it. |
| [Pocket](slide-a-key_musical_transposer_pocket_edition.pdf) | A spinning disk on a base card, joined with a brass paper fastener. |

Print at **100% scale**, not "fit to page", so the strips and rings line up. Assembly instructions are on each sheet.

Teachers: the [Teacher's Guide](TEACHERS_GUIDE.pdf) has a ready-to-use lesson and classroom ideas.

## Free to Print and Share

Print it, photocopy it for your students or band, and pass it on. Please don't sell it.
