# Slide-a-Key Musical Transposer

**No batteries! No app! No subscription!**

Slide-a-Key is a free, printable paper tool for moving notes, melodies, and chord charts from one key to another. Line up the key you're in with the key you want, then read off the matching notes. It works in all 12 keys.

**Visit the website: [www.slideakey.com](https://www.slideakey.com)**. You can try it on screen there before you print.

This repository holds the files for that website.

## Print Your Own

| Edition | How it works |
|---|---|
| [Classic](slide-a-key-classic-transposer.pdf) | Fold the slider over the top edge of the page so it hooks on and slides along it. |
| [Pocket](slide-a-key-pocket-transposer.pdf) | A spinning disk on a base card, joined with a brass paper fastener. |
| [Sleeve](slide-a-key-sleeve-transposer.pdf) | The slider runs inside a folded paper sleeve, and the notes show through a window. |

Optional for the Classic Edition: the [Chord Family Classic](slide-a-key-classic-chord-family-add-on.pdf) hooks over the top edge and marks the main chords (I, IV, V, and vi) in any key.

Optional for the Pocket Edition: the [Chord Family Pocket](slide-a-key-pocket-chord-family-add-on.pdf) turns on top of the wheel and marks the main chords (I, IV, V, and vi) in any key.

Optional for the Sleeve Edition: the [Chord Family Sleeve](slide-a-key-sleeve-chord-family-add-on.pdf) slips over the Sleeve and marks the main chords (I, IV, V, and vi) in any key.

Print at **100% scale**, not "fit to page", so everything comes out full size. Each sheet has a print check at the bottom: a line that measures 50 mm. The sheets are US Letter size but print fine on A4. Assembly instructions are on each sheet.

Have a Cricut? The [Cricut cut files](slide-a-key-cricut-kit.zip) let it cut out the Pocket and Sleeve Editions, and the add-ons, for you, using Print Then Cut.

Teachers: the [Teacher's Guide](slide-a-key-teachers-guide.pdf) has a ready-to-use lesson and classroom ideas.
